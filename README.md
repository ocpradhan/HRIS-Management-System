# Backend Engineering Project (In Progress)

This repository demonstrates my backend architecture choices, database modeling, and automated testing workflows. I am currently finalizing the integration test suites and frontend pairing.

### 🛠️ Tech Stack & Tools
* **Runtime & Framework:** Node.js, Express.js
* **Database & ORM:** PostgreSQL, Prisma ORM
* **DevOps & CI/CD:** Docker, GitHub Actions
* **Testing:** Jest (Integration Testing)

### 🚀 Key Architecture Highlights
* **Clean Directory Structure:** Layered architecture separating routes, controllers, and database logic.
* **Containerization:** Pre-configured Docker setup for consistent local development and isolated test databases.
* **Robust Type Safety & Schemas:** Relational database schemas managed cleanly via Prisma.
